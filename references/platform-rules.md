# 平台发布规则

核对日期：**2026-10-10**。以下覆盖当前支持的全部 9 个“平台 × 内容类型”组合。**程序限制**是当前输入检查或适配器支持范围；**官方规则**只用于注明的发布入口；**未核实**表示需要在目标账号的编辑器确认，不表示无限制。账号权限、平台审核、版权或内容政策不能仅靠本地字数和文件检查判定通过。

## 统一规则与处理方式

审核按 **平台 + 发布入口 + 字段 + 实际媒体类型** 选择规则。视频素材既可能出现在“视频”任务，也可能出现在“动态”任务；两者共用文件、大小、时长等检查，按实际入口应用对应限制。文字、话题、图片、封面、账号与声明也采用同一分类方式。共有检查集中维护，适用差异在下表明确标出。

| 规则类别 | 什么时候检查 | 统一处理 |
| --- | --- | --- |
| 标题、正文、短标题 | 目标入口实际支持或要求该字段时 | 检查实际值及适用条件；正常回报只显示原值，有问题才说明相关计数与限制，不跨入口套用 |
| 标签与原生话题 | 提供标签或入口要求标签时 | 检查名称、数量及适用的最终正文计数；原生话题选择与平台实体计数仍需页面确认 |
| 视频素材 | 提供视频文件时，包括动态附带的视频 | 统一核验本地文件及可读取的规格，再应用当前平台/入口的格式、大小、时长限制；像素或账号条件未核验时单独提示 |
| 图片与封面 | 使用图片或启用自定义封面时 | 检查真实文件、数量及适用的大小、尺寸、比例；动态图片与封面使用各自用途的限制 |
| 登录、账号、声明和权限 | 目标平台要求时 | 使用已有事实与确认值；登录交人工处理，未知声明不猜填，账号能力不由文件合格推断 |

发现已知错误或必填缺项时，第一环节集中提示，任一目标失败就阻断全部填写和上传。未知或只能在页面确认的规则在私有报告列为“待核验”，需要用户处理时才列入问题区，不能当作无限或已通过；不适用的字段标为“不适用”。修正输入后重新审核，不自动改文案、裁剪素材或切换发布入口。登录检查与内容审核分别报告。

统一的是适用判断、检查和处理方式。不同入口已有的差异继续保留：例如小红书视频标题与动态标题目前使用不同计量规则，YouTube 的账号条件不用于其他平台，视频号短标题只属于视频号入口。下表中的“视频 / 动态”用于说明入口，不决定素材是否需要视频检查。

## 文字与标签

表中最小长度“1”表示至少一个非空白字符。UTF-16 单元是 JavaScript `length`：常见汉字计 1、普通 emoji 通常计 2；Unicode 码点中普通 emoji 通常计 1，组合 emoji 可能含多个码点。小红书独立视频标题采用程序已有权重：ASCII 码点 0.5，其余码点 1。X 使用固定官方 [twitter-text v3 规则](https://github.com/twitter/twitter-text/blob/master/config/v3.json)：常见中文计 2、识别的单个 emoji（含肤色或 ZWJ 组合）计 2、每个识别的 URL 计 23；不能套用普通字符串长度。

| 内容 / 平台 | 标题最小 / 最大 | 正文、简介或短标题 | 标签 / 话题 |
| --- | --- | --- | --- |
| 视频 / 小红书 | 必填；1 个非空白字符起，最多 20 个上述加权单位【程序】 | 当前适配器不写普通正文；共同简介用于其他支持平台，审核中标明此项不适用。官方网页正文上限未核实 | 至少 1 个真实话题；标签 `.` 不接受；数量最大值未核实【程序】 |
| 视频 / 抖音 | 必填，1–30 个 Unicode 码点【程序】 | 简介可空；程序不接受在简介中混入行内 hashtag，标签另给；官方网页最大长度未核实 | 1–5 个真实话题【程序】 |
| 视频 / B站 | 必填，1–80 个 Unicode 码点【程序】 | 简介必填，至少 1 个非空白字符；网页最大长度未核实 | 1–10 个标签【程序】；自动补标签关闭。数量与标题值不作为所有 B站入口的统一官方上限 |
| 视频 / 视频号 | 共享标题必填，用于任务身份；程序尚无其最大值 | 描述必填，至少 1 个非空白字符；可选 `wechatShortTitle` 留空或至少 6 个 Unicode 码点【程序/已有页面路径】。**短标题最大值、描述最大值与官方计数规则未核实**，不把网传“6–16字”写成已确认规则 | 至少 1 个真实话题；数量最大值未核实【程序】；最终描述含原生话题 |
| 视频 / YouTube | 必填，1–100 个 Unicode 码点【程序】；官方最多 100 characters | 程序要求非空、最多 5000 个 Unicode 码点，并拒绝网络链接；官方说明最多 5000 characters，禁止链接是本工具限制，并非 YouTube 通用禁令。[上传说明](https://support.google.com/youtube/answer/57407?co=GENIE.Platform%3DDesktop) | 可空；逗号拼接后最多 500 个 UTF-16 单元【程序】；tags 字段与正文 hashtag 不同 |
| 动态 / X | 无独立标题，填“无” | 非空正文；普通帖子上限 280 个平台加权单位，附加标签也计入；每个 URL 按 23 计。Premium 长帖未接入。[普通帖子](https://help.x.com/en/using-x/how-to-post)、[链接计数](https://help.x.com/en/using-twitter/how-to-tweet-a-link.html) | 可空；按 `#标签` 追加到正文【程序】；未接入独立话题 ID |
| 动态 / 微博 | 无独立标题，填“无” | 非空正文；普通网页动态的官方最大长度、计数方式未核实，程序未设固定字数上限 | 可空；按闭合的 `#标签#` 追加到正文【程序】 |
| 动态 / 小红书 | 可空；填写时最多 20 个 UTF-16 单元【程序】 | 非空正文；第一环节要求 ≤1000 个 UTF-16 单元【程序保守限制】；添加原生话题后，编辑器仍须满足 `descLength ≤ 1000`。原生话题的最终计数待页面确认，不作为所有客户端的官方字数规则 | 可空；逐个选择精确同名的原生话题，普通 `#文字` 不视为已添加话题；最大数量未核实 |
| 动态 / 即刻 | 无独立标题，填“无” | 非空正文；官方最大长度和计数单位未核实，程序未设固定最大值 | 可空；按 `#标签` 追加普通正文，不代表选择圈子【程序】 |

输入标签仅用中文顿号 `、` 分隔，不按空格拆分。动态标签不接受空名称、内部空白、重复名称；不生成标签。平台专属标题或正文只使用你明确提供的覆盖值，否则沿用共同原文。共同内容必须满足每个所选平台的适用规则，不能只通过其中一个平台就开始上传。

## 视频素材：独立视频与动态附带视频

标准模板接受一段本地 MP4 / M4V / MOV；下表中的官方格式清单不等于模板支持范围。两类入口都检查路径明确、存在且非空的本地视频，按下表应用对应规格。动态视频当前只接入 MP4，不接入远程视频 URL、自动转码、自定义封面或字幕文件。MiB = 1,048,576 bytes；MB = 1,000,000 bytes；GB = 1,000,000,000 bytes。扩展名或容器元数据检查不等于完整解码通过。

| 发布入口 | 可核验格式 / 文件大小 | 时长最小 / 最大 | 画幅、账号条件与自定义封面 |
| --- | --- | --- | --- |
| 视频 / 小红书 | 程序要求本地文件存在；官方网页完整格式清单和最大文件大小未核实 | 最短、最长均未核实；不当作无限 | 视频像素/画幅硬限制未核实。自定义封面需要 **3:4**【程序】；标准模板默认取视频首帧 |
| 视频 / 抖音 | 程序要求可读取时长的 **MP4 / M4V / MOV**；网页文件上限未核实 | 程序要求可核验且 `>0`；网页最长时长未核实 | 视频分辨率/画幅硬限制未核实。自定义封面同时提供 **3:4 与 4:3**【程序】 |
| 视频 / B站 | 程序要求本地文件存在；网页格式全集和单文件最大值未核实 | 网页最短、最长未核实 | 视频分辨率/比例硬限制未核实。自定义封面同时提供 **4:3 与 16:9**【程序】；不自动选择分区 |
| 视频 / 视频号 | 程序要求本地文件存在；网页格式全集和最大值未核实 | 网页最短、最长未核实 | 视频分辨率/比例硬限制未核实。自定义封面同时提供 **3:4 与 4:3**【程序】；登录和选账号由人工完成 |
| 视频 / YouTube | [官方支持格式](https://support.google.com/youtube/troubleshooter/2888402?hl=en)包括 MP4、MOV、MPEG、AVI、WMV、FLV、WebM、ProRes 等；音频文件不能直接作视频上传。绝对上限 **256 GB**，还须满足时长上限 | 绝对上限 **12 小时**，与大小限制同时满足；普通未验证账号默认最多 **15 分钟**，更长视频需账号验证。官方未公布一般视频的最短时长。[长视频说明](https://support.google.com/youtube/answer/71673?co=GENIE.Platform%3DDesktop) | 视频播放器适配横、竖、方形画幅，16:9 是电脑标准画幅而非唯一准入比例。[画幅说明](https://support.google.com/youtube/answer/6375112?co=GENIE.Platform%3DDesktop)。本工具自定义封面采用 **16:9**；官方要求具备自定义封面权限，建议 JPG/PNG、3840×2160、视频封面最低宽 640，**桌面 <50 MB，移动 <2 MB**；后者不能当桌面通用限制。[封面说明](https://support.google.com/youtube/answer/72431?hl=en) |
| 动态 / X | 本地 MP4，≤512,000,000 bytes（512 MB）【程序】 | 可核验且 `>0`、≤140 秒 | [官方普通账号](https://help.x.com/en/using-x/x-videos)也是 140 秒 / 512 MB；Premium 更大范围未接入。动态自定义封面未接入 |
| 动态 / 微博 | 本地 MP4，≤512,000,000 bytes【程序】 | 程序未设最长时长；网页时长限制未核实 | [官方视频帮助](https://kefu.weibo.com/faqdetail?id=21503)写 PC 最高 15 GB、手机最高 4 GB；当前工具范围更窄，不套用手机 3 秒下限。动态自定义封面未接入 |
| 动态 / 小红书 | 本地 MP4，≤512,000,000 bytes【程序】；网页最大值未核实 | 网页最短、最长未核实 | 视频像素/画幅硬限制未核实；动态自定义封面未接入。[分享 SDK](https://agora.xiaohongshu.com/doc/android)的视频规格不作为原生网页限制的证明 |
| 动态 / 即刻 | 本地 MP4，≤104,857,600 bytes（100 MiB）【程序】 | 可核验的 **3–360 秒**，含边界【程序】 | 页面验收检查长边 ≤1920、短边 ≤1080；本地未读出尺寸时标为待核验。[官网](https://www.okjike.com/)未公开完整技术上限；动态自定义封面未接入 |

标准模板默认提取视频首帧作为封面；提供自己的 JPEG/PNG 时优先使用该图片，高级 JSON 可显式禁用。提供单张 JPEG/PNG 时，程序生成所需比例副本，保留完整画面、按需缩小并补黑边，不裁切、不放大、不改原图；随后检查实际图像尺寸及文件。显式按比例提供的封面沿用原校验。除上表明确列出的条件，其他平台封面大小、最小/最大像素、视频编码、码率、帧率与音轨限制尚未由当前网页官方资料核实；这些检查不能报告为“已通过”。推荐规格与平台拒绝阈值分开看待。

## 图片素材：数量、格式与大小

动态必须有非空正文和一种媒体：图片或单段视频，不混选。标准模板只接受本地绝对路径；高级 JSON 内容包另支持公共 HTTPS 图片，见[高级输入](workflow.md#输入与执行)。两种方式均校验真实 JPEG/PNG 字节，不接入 GIF。视频附带自定义封面时，仍按上表的封面用途与比例检查，不能套用动态图片数量规则。

| 动态入口 | 图片数量【程序】 | 单张大小【程序】 | 适用范围与官方差异 |
| --- | --- | --- | --- |
| X | 1–4 张 | ≤5,000,000 bytes（5 MB） | [官方照片帮助](https://help.x.com/en/using-x/posting-gifs-and-pictures)写最大 5 MB，严于其他入口的 5 MiB |
| 微博 | 1–9 张 | ≤5 MiB | [官方图片帮助](https://kefu.weibo.com/faqdetail?id=12483)写单张 <20 MB、支持 GIF/JPG/PNG；当前工具范围更窄 |
| 小红书 | 1–18 张 | ≤5 MiB | [分享 SDK](https://agora.xiaohongshu.com/doc/android)的 1–18 张不作为原生网页限制的证明 |
| 即刻 | 1–9 张 | ≤5 MiB | [官网](https://www.okjike.com/)未公开完整图片技术上限 |

图片最大宽高/比例等未知项目需目标网页确认。图片按给定顺序上传；重复图片来源、混选图与视频、超过程序数量或大小均在准备前拒绝。HTTPS 图片下载拒绝私网地址、凭据、自定义端口、重定向越界、超时和超限内容。

## 常规设置与尚未接入的字段

- 视频默认：非儿童受众、无付费推广、无逼真合成、YouTube 公开、标准许可、允许嵌入及订阅通知；分类/语言/播放列表留空；原创/自制开启、视频首帧封面、视频号短标题留空。本次明确值优先于持久偏好和内置默认。`aiGenerated` 仅采用你提供的事实或偏好，不从标题、标签或素材名推断。
- 小红书/B站/视频号的现有独立视频适配器使用原创/自制路径，明确非原创时会拒绝，不会覆盖你的声明。动态没有统一原创或 AI 声明接口。
- 视频号登录、账号选择由你在第一环节完成；所有平台的验证码、权限、风控和未接入的必填字段会停下并提示。程序不代填未知事实、不猜账号、不自动选择 B站分区。
- 当前动态未接入位置、投票、定时、付费可见、圈子选择或独立内容声明；需要时会说明不支持。独立视频/动态默认由你手动发送；本次“是否全自动：是”时核验后自动发送。
- 恢复任务沿用原内容、素材、平台、账号关联与有效设置，不用更新后的默认值改写旧任务；身份变化或上传结果未知时停止，不创建副本绕过。

## 官方规则来源与适用边界

YouTube 与 X 的链接支持上表中对应入口的公开规则。小红书、抖音、视频号与若干文章/动态字段的完整网页规格需要登录后才能核验；缺少公开来源的项目已经逐项标注。小红书[创作服务平台](https://creator.xiaohongshu.com/)、抖音[创作者服务平台](https://creator.douyin.com/)、[B站创作中心](https://member.bilibili.com/)、[视频号助手](https://channels.weixin.qq.com/)是实际使用入口。

[抖音上传 API](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/upload/)的直传/分片规格、[B站开放平台错误码](https://open.bilibili.com/doc/4/8673959e-f7bb-56e6-6e68-d225f971b81b)的接口限制，以及小红书分享 SDK 规格，都不能直接替换本工具的网页规则。历史页面记录只能证明当时的入口与账号。

这份清单覆盖工具已支持的发布字段和素材要求，不代表已经收录平台的全部审核政策。规则未公开、账号权限不足或页面临时新增要求时，第一环节会标明尚待确认的项目；本地检查通过不保证平台审核通过。
