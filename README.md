# 168 同步发布

当前版本：`0.0.28`。

给开发者和自媒体人的本地 AI Skill：**一份文案和素材，准备到多个平台；通过 Profile 使用不同账号，默认由你手动发布，也可为本次任务开启全自动。**

- **减少重复操作**：一次提供标题、正文、标签和素材，确认后逐平台填写并提交文件。
- **支持多账号**：用不同 Ego Profile 保存不同账号的登录状态。先在 Ego 切换到目标 Profile，再用 `Profile：名称` 分别运行任务；Skill 会核对当前 Profile，不自动切换账号。
- **先检查，再执行**：集中检查登录、必填内容和已支持的媒体规格，列出需要处理的问题，确认后才填写和上传。
- **两种发布方式**：`是否全自动：否` 保留确认、配置与人工发布；填“是”后检查通过即连续执行到最终发布，有问题才暂停。
- **中断后继续原任务**：处理登录或字段问题后，可复用原任务和页面继续；已配置并交回的平台会跳过，提交结果不明时不会自动重传。
- **源码可按需修改**：自有代码采用 [MIT 许可](LICENSE)，可调整平台适配和流程。模板提供本次任务的全自动开关，默认关闭。

| 平台 | 图文 | 视频 |
| --- | --- | --- |
| X | 支持 | 支持 |
| 微博 | 支持 | 支持 |
| 小红书 | 支持 | 支持 |
| 即刻 | 支持 | 支持 |
| 抖音 | 支持 | 支持 |
| B站 | 支持 | 支持 |
| 视频号 | 支持 | 支持 |
| YouTube | 支持 | 支持 |

根据媒体自动判断：图片是图文，视频是视频，无需填写“类型”。默认平台统一保存在 `platforms.media`；图文和视频沿用相同的默认平台。

它接收已准备好的内容，不创作标题、正文、标签或视频；视频默认提取首帧作为封面；不支持文章发布。

新增抖音图文、B站动态图文、视频号图文和 YouTube 社区帖子入口。新入口已完成本地文件检查、模拟保护与只读页面核对，尚未验证真实素材上传与发布；平台更改、账号权限或无法证明上传关联时，会暂停并交回原页面。

## 安装

需要 **macOS、Node.js 24、FFmpeg（提取视频首帧）、[Ego](https://lite.ego.app/)、ego-browser Skill 和 CLI**。AI 助手需要支持加载本地 Skill、读取本地文件、执行命令并操作 Ego 页面。无需 `npm install` 或构建；Ego 首次引导和平台账号登录由你完成。

从 [GitHub 仓库](https://github.com/guoshunfa/168-publisher) 下载源码，或运行 `git clone https://github.com/guoshunfa/168-publisher.git`。将下面路径替换为含根 `SKILL.md` 的本地目录，再发给 AI：

```md
请帮我把 /absolute/path/to/168-publisher 安装为全局 Skill。
先读取该目录的 references/installation.md，检查运行依赖，按当前 AI 工具的规则安装，并验证根入口已加载、嵌套依赖入口未启用。
```

完成后应能调用 `$168-publisher`。不支持这种语法的工具按[安装说明](references/installation.md)读取入口。Codex 远程安装使用内置 `skill-installer`；本地维护软链接沿用用户已明确指定的方式。

## 使用

**模板**

替换 `<...>`，将整段发给 AI。媒体每行一个本地绝对路径，不加编号；可带一对匹配的单/双引号；多张图片可继续加行。

```md
$168-publisher
是否全自动：否
标题：<标题，没有填“无”>
正文：<正文或视频简介>
标签：<标签，用“、”分隔；没有填“无”>
媒体：
<视频或图片的完整路径>
封面：默认
平台：<平台名称，用“、”分隔>
```

- **是否全自动**：放在标题上方，填“是”或“否”，省略默认为“否”。“是”授权当前内容与目标平台连续执行到最终发布；不会成为下一次任务的默认值。
- **标题与正文**：需要标题的平台使用共享标题；图文中小红书、抖音、B站和视频号使用标题；YouTube 帖子不使用独立标题，X、微博、即刻不使用独立标题。图文正文必填，视频不需要简介时填“无”。
- **封面**：X、微博、即刻的视频无独立封面字段；视频填“默认”、留空或省略时，提取首帧并上传至支持的封面项。填写一张 JPEG/PNG 的完整路径时，优先使用该图片，不提取首帧；图文不支持自定义封面。
- **媒体**：一张或多张 JPEG/PNG 自动判定为图文；一段 MP4 / M4V / MOV 自动判定为视频。不能混选图片和视频，各平台继续检查实际文件格式及规格。标准模板不接受远程 URL。
- **标签**：仅用中文顿号 `、` 分隔，空格不分隔；图文标签名不能含内部空白。小红书、抖音、B站、视频号的独立视频要求标签，填“无”会提示补齐。
- **平台**：多个名称用 `、` 分隔，也可写平台 ID。“所有”或“所有平台”使用统一的 `platforms.media` 列表；初始含八个平台，图文和视频均使用该列表。

需要时，在模板末尾追加可选字段：

| 字段 | 用法 |
| --- | --- |
| `视频号短标题：……` | **仅在携带视频且目标包含视频号时添加**；其他任务必须省略整行，不能保留空字段。默认留空，不从共享标题复制 |
| `Profile：默认` 或 `Profile：名称` | 省略时沿用配置，配置为空则用 Ego 当前默认项；指定名称只核对当前 Profile，不自动切换 |

**示例**

这是一条发到 X 和微博的图文。把示例路径换成自己的真实文件：

```md
$168-publisher
是否全自动：否
标题：无
正文：今天把重复发布的流程整理成了一个 Skill，减少重复填表与上传。
标签：AI、视频生成
媒体：
/absolute/path/to/demo.png
封面：默认
平台：X、微博
```

脚本直接解析模板，保留原文与素材顺序。缺项、媒体混选、标签格式错误或不支持的平台组合会先列出具体问题；补齐后再继续。

## 提交后会发生什么

默认“否”按以下流程执行。选择“是”时，预检没有问题就自动继续，不再等待“继续”；配置后会等待上传与处理完成，核验原文、素材及账号，再点击最终发布并读取平台回执。未登录、验证码、必填项缺失、原创权利待确认或操作失败时才暂停并提出具体问题。处理后继续原 Job，避免重复上传或发送。

1. **检查登录与内容**：在一个 Ego 空间打开全部目标页面，检查登录、文案和素材，展示确认清单与待处理问题。这个阶段不填写文案或上传；登录、验证和选账号由你完成。
2. **确认后配置**：你回复“继续”后，复用原任务、空间和页面，逐平台填入已确认的内容并提交素材。
3. **交给你查看**：配置动作完成后交回全部页面，平台可能仍在上传或转码。你检查内容并点击最终发送。

`configured` 只表示填写与文件提交动作完成，**不表示上传结束、永久保存或已发布**。遇到登录失效、权限或字段阻塞，会列出未完成项并交回原页面；处理后要求“继续原任务”，避免重复创建。文件提交结果未知时不自动重传。

X 点击受阻时，程序确认尚未触发且内容和账号未变后只补一次点击；小红书重编码图片可通过原文件回执和完全相同的像素继续核验。已经发送或结果不明时仍不会自动重发。

四平台图文原任务已有发布成功回执，其中 X 与小红书经用户确认后恢复。新版通过模拟回归和 Ego 本地页面验证，尚未重新向真实平台发布。具体证据见[验证范围](references/workflow.md#验证范围)。

## 边界与默认设置

- 只使用你提供的文字、标签和素材，不分析媒体或文件名来生成文案。小红书独立视频当前不写正文；同时选其他平台时，共同简介只用于支持的平台。
- 视频内建默认包括原创/自制、非儿童、无推广、无逼真合成、支持平台的视频首帧封面和空的视频号短标题；**YouTube 默认为 public（公开）**。本次明确值优先于保存的设置，再优先于程序默认；确认清单展示实际生效值。AI 生成声明只采用你提供的事实。
- 当前部分视频适配器仅支持原创/自制路径，明确非原创时会停止。图文未接入自定义封面、投票、定时、位置或圈子选择。详见[平台发布规则](references/platform-rules.md)。
- 准备内容会将所选文案和素材提交到目标平台；私人素材、配置和任务记录应留在源码目录之外。
- 本地检查不能保证平台审核通过；未知规格和账号条件仍需页面核验。“否”时由你手动发送且不等待后台处理；“是”时限时等待并发布，明确成功回执才记为已发布，已点击但无回执只记为待确认。

## 配置与详细说明

使用 $168-publisher，配置。
